# Portfolioの写真追加・情報編集

Pictures欄の写真は、サムネイル・作品番号・タイトル・操作ボタンを持つカードで表示します。「写真情報を編集」で、対象写真のプレビュー付きポップアップを開きます。以前の横並びの小さいカード内に入力フォームを展開する構造をやめ、入力欄とボタンのはみ出しを修正しました。

タイトル・キャプション・カメラ・レンズ・F値・シャッタースピード・ISO感度はすべて任意です。空欄は公開ページに表示しません。「編集内容を反映」で編集画面へ戻り、最後にページ下部の「Save changes」でPortfolioを保存します。キャンセル・閉じる・Esc・背景のクリックでは、今回ポップアップ内で行った編集を破棄します。反映済みの編集内容はそのまま残ります。

Exifはポップアップを開いたときに読み込み、取得中も手入力できます。読み込み完了前に入力・削除した欄や、既に保存した手入力の値を自動情報で上書きしません。別の写真を開いてから届いた応答も、その写真の入力欄には反映しません。取得に失敗した場合は再読込または手入力を選べます。空欄にして反映した値は、次回開いたときも空欄を維持します。

PCは写真と入力欄を左右に、スマホは上下に配置します。ポップアップのヘッダーと操作ボタンを画面内に保ち、本文をスクロールできます。閉じた後は元の編集ボタンへフォーカスを戻します。作品の画像自体は縦横比を保ち、サムネイルでも切り抜かずに表示します。

「写真を追加」から複数画像を選べます。1枚20MB以下・最大500枚の制限を維持し、アップロードの枚数と進捗を表示します。途中で失敗した場合、追加済みの画像は一覧に残し、追加できた枚数と既存のエラー番号を表示します。アップロード中は画像操作を無効にし、終了後に先頭・末尾の移動制限を正しく戻します。「前へ」「後へ」「削除」を使っても、写真ごとの編集内容はその画像と対応したまま保存します。アイコンの操作は作品一覧から分離しています。
