# 提出詳細の配置操作とスクロール位置

提出詳細の「配置・サイズを修正」では、写真のドラッグ・矢印キーによる移動、スナップ・間隔・用紙サイズ・向き・整列の変更で同じ画面を描き直します。描き直す前に内部の `.se-body` の縦横スクロール位置を取得し、描画・イベント再設定後に同じ位置へ戻します。

提出内容と配置画面の切り替え、作品・展示の変更、タブの切り替え、確認画面への移動は新しい画面の先頭を表示します。写真の配置・寸法・保存・独立した出展者の下書きの取り扱いは既存処理を維持します。

合成データのブラウザテストで修正前はドラッグ後に 140px から 0px へ戻ることを再現しました。検証ではPC・スマートフォン幅、内部とページのスクロール位置、連続操作と保存、画面切り替え時の位置を確認します。
