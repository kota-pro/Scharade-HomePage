# 展示室編集と再利用の改修（2026-10-09）

既存の写真展管理に、運営以上が使える名前付き展示室ライブラリを追加した。保存データは `DATA_DIR/exhibition-rooms.json` に置き、写真展の削除とは独立して保持する。重複した保存名は新規作成を拒否し、選択した保存先を更新する。更新時は版番号を照合する。読み込みは部屋・扉・展示台・注記のIDを採番し直し、以前の写真展の作品配置を持ち込まない。

編集画面は25〜800%の倍率、拡大・縮小・全体表示、画面の移動、電源・ドア記号・文字・数字・四角形・楕円、作品の展示者名表示に対応した。頂点をドラッグしている間はページのスクロールを抑止し、キャンセル時は開始前へ戻す。各ツールのカーソルを指定通りに切り替える。描画中の頂点クリックで閉じる操作は、交差がない3点以上の図形に限定する。

新しい図形・注記と展示者名は各室SVG/PNG、全室PDFでも表示する。既存の部屋は注記なし・展示者名表示ありとして読めるため、データ移行は不要。ブックの作品画像は任意に変更した。未添付の枠は下書きでは保持し、最終提出時は空の画像一覧へ正規化する。単写真・組写真の画像、各作品のタイトルは引き続き必須。Google連携の作品画像URLの欄は元から任意のため、Apps Scriptの再公開は不要。
