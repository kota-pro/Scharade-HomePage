# タイトルボードの鉤括弧とふりがな

作品の `titleBoard` は省略可能です。旧データと省略時は「鉤括弧あり・ふりがななし」を維持します。タイトル本文は加工せず保存し、表示・PDF生成時に鉤括弧の有無を適用します。

ふりがなを有効にすると漢字1文字ごとの入力欄を表示します。読まない字は空欄で構いません。「語句を追加」で漢字を含む2文字以上の範囲を指定すると、その範囲全体の中央に読みを置きます。例: 永遠（ずっと）。重なる語句は追加できず、同じ語句が複数ある場合は文字位置で対象を選びます。語句を解除すると、それまでの文字ごとの読みを再利用できます。

読みの自動生成は行いません。読みは作者が指定し、配置を自動計算します。ふりがなはZen Old Mincho Regularの7pt、タイトルは21pt Bold、元の本文・QRの位置を維持します。ふりがなが隣と重なったり印刷枠を超える場合は、フォームと最終提出・PDF生成で警告します。

範囲はUnicodeコードポイントのstart/endと元の文字列baseで保存します。タイトルを編集すると変化していない前後の読みだけを移動・保持し、置き換えた文字に古い読みを流用しません。IME変換中は範囲を組み直さず、変換完了時に反映します。

下書き・提出版・運営の修正履歴・プレビュー・配置図のタイトルボード・PDFで同じ設定を利用します。Google連携では追加の任意項目「タイトルボード表示設定」にJSONを保存し、再取り込みでも保持します。列のない既存シートを再取り込みしたときは保存済みの設定を維持します。既存Googleフォームは同じIDのまま更新し、複製しません。
