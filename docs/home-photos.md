# トップページのPortfolio写真と除外設定

Homeのメイン写真・フィルム写真は、ログアウト時のPortfolio一覧に掲載される会員の横長写真から選びます。microCMSに登録された画像の幅が高さより大きい写真だけが対象です。縦長・正方形・寸法不明の写真、管理専用Portfolio、アイコン未登録のPortfolioは対象外です。同じ画像が複数のPortfolioにある場合も候補は1枚として扱います。除外設定のポップアップにも横長写真だけを表示し、既存の除外設定は保持します。

ページを開くたびに、除外されていない候補をランダムに並べ、フィルムに最大20枚、その先頭の最大3枚をメイン写真として表示します。従来の配置・フィルムの動き・写真拡大・スマホでのフィルム非表示は維持します。写真配信には表示サイズ別の画像と遅延読み込みを使用します。

フィルム写真と上下のフィルム穴は、左へ同じ速度（毎秒30px）で流れ、ホバー中も止まりません。クリックしたまま左右にドラッグするか、トラックパッドで二本指の横スワイプをすると、写真と穴が操作と同じ方向・移動量で動きます。離すと慣性で徐々に減速し、通常の左向きスクロールへ戻ります。縦方向のスクロールはページ操作に使え、ドラッグでは写真の拡大を開きません。写真を拡大している間、フィルム内のリンクにキーボードフォーカスがある間、および端末の「動きを減らす」設定が有効な場合は両方の自動スクロール・慣性を停止します。動きを減らす設定でも、ドラッグ・横スワイプ中は操作した分だけ動かせます。

## 除外する写真を選ぶ

1. 管理者でAdmin → 「Index / Homeの編集」を開きます。
2. 「メイン写真・フィルム写真の除外設定」から「写真の除外設定を開く」を押します。
3. 写真を押して「除外中」にします。もう一度押すと表示候補に戻ります。Portfolio名の検索、すべて／表示候補／除外中の切り替え、36枚単位のページ送りを利用できます。
4. 「選択を反映」を押します。この時点では保存されていません。「キャンセル」や閉じる・Escapeでは、このポップアップ内の変更を破棄します。
5. 「下書きを保存」→「プレビュー」で確認し、「公開する」を押します。公開するまでは訪問者が見る写真候補は変わりません。

除外はHomeのメイン写真とフィルムの両方に適用します。元のPortfolioの写真を削除・非公開にする操作ではありません。「直前の公開版へ復元」では文章と一緒に除外設定も戻ります。公開したくない写真はPortfolio側の公開状態も別に管理してください。

写真をすべて除外した場合、対象写真がない場合、または取得に失敗した場合はメイン写真とフィルム写真を表示しません。除外した写真や旧 `card_image` の写真を代替表示することはありません。候補が1〜2枚なら、その枚数だけ表示します。新しくPortfolioに追加された写真は自動的に候補へ入るため、必要に応じて除外してください。

## 保存・取得の仕様

- 保存先：`DATA_DIR/site-content.json` の `pages.home`。`draft`／`published`／`previous` 内の `excludedPhotoIds` に写真の識別子を保存します。文章と同じ更新番号で競合を検出します。
- 識別子：microCMSの画像URLから変換サイズ等のクエリを除いてSHA-256化した値。同じ画像の小さい版・大きい版や、別Portfolioにある同一画像にも除外が有効です。画像を別ファイルとして再アップロードした場合は別の候補になります。
- 旧形式の下書き・公開版・復元元は、文章を維持したまま除外なしとして読み込みます。データ移行コマンドは不要です。
- 一時的に非公開・削除された写真の除外設定も保持し、同じ画像が再掲載されても除外を継続します。最大5,000枚の除外設定を保存できます。
- 候補取得は公開Portfolioを100件ずつ最後まで取得します。既存のCMSキャッシュを使い、通常は最大60秒でPortfolioの変更を反映します。管理画面からの公開時はキャッシュを無効化します。
- 管理用候補一覧は `GET /api/admin/home-photos`。管理者のみ利用でき、共有キャッシュに保存しません。ポップアップを開く時に読み込み、画像は現在のページのサムネイルだけ取得します。失敗時は除外設定を空に置き換えず、再読み込みを案内します。
- 旧microCMS `card_image` はHomeでは参照しません。既存コンテンツは削除していません。
