# 組写真ツールのポップアップ

出展フォームの「組写真ツールを開く」と、運営の提出修正画面の「配置・サイズを修正」から、専用のポップアップを開きます。画面内に直接配置ツールを展開しません。グリッド・端のスナップ、ドラッグ・矢印キー移動、ピンチ拡大縮小、間隔編集と整列に加え、写真ごとの紙サイズ・向き・寸法・座標・回転、個別追加・削除を操作できます。

ポップアップはフォーム外に保持します。編集中は背景のフォームを再描画せず、内容を更新して自動下書き保存を続け、閉じる時に背景のプレビューを更新します。操作中のスクロール位置を維持し、閉じる際は元の入力欄へ戻ります。右上の×と下部ボタンで閉じます。Escapeは写真の選択を解除し、選択のない状態ではポップアップを閉じます。間隔入力の小さいポップアップはその上に開きます。

出展者の変更は既存の自動下書き保存を使います。運営の修正は提出内容へ反映し、元の提出確認画面の「変更内容を確認」から保存します。空の組写真も開けます。写真を追加すると配置キャンバスを表示します。保存済みのデータ形式・提出履歴・作品数の上限は変更しません。
