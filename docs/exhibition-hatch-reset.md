# 図形のハッチング・内部注記・リセット

図形のプロパティで「ハッチングで色をつける」を選び、塗りの色を指定します。閉じた四角・楕円・記号・ペンのパスに対応し、開いた線や画像・文字には塗りを付けません。`fill` は従来の「none」または色を保存し、色がある図形を手描き風のSVGパターンで描画します。ベタ塗りや外部画像は使用しません。

名前は図形内で折り返し、指定した文字サイズを上限に必要な分だけ縮小します。名前の背景は白く抜き、ハッチングと重ならないようにします。注記は図形の外側へ表示し、寸法・選択範囲・整列には含めません。凹形のパスでは名前を内側の矩形領域へ配置します。編集画面・プレビュー・PNG/PDF・文字をアウトライン化したSVGで同じ描画処理を使います。

保存履歴の右隣にリセットボタンを置きます。確認画面で実行すると、当該写真展の全展示室、壁、設備、図形と作品の配置を空にし、寸法入力欄も空欄に戻します。提出作品・回答・元画像・保存履歴は削除しません。確認のキャンセルでは図面を変更しません。リセットは通常の共同編集操作として保存し、Undo/Redoと過去の保存履歴から復元できます。

空の編集画面では、ペンで3〜32頂点の閉じた展示室を描くか、横幅・縦幅を入力して四角形の展示室を追加できます。ペンはクリックで頂点、ドラッグで曲線、頂点またはEnterで閉じる、Escで取消です。未確定の頂点はUndo/Redoできます。

キャンバスとツールにフォーカスがある場合、⌘Z / Ctrl+Zで戻し、⇧⌘Z / Ctrl+Shift+Zでやり直します。空の図面でもリセット前の図面を復元できます。文字入力欄ではブラウザの通常の文字編集Undoを維持します。
