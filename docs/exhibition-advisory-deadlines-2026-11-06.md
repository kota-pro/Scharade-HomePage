# 参加投票・出展・シフトの期限と提出警告

設定した提出期限は、期限超過を知らせる目安として扱います。対象者・承認済みアカウント・参加状態・受付開始の条件は維持します。

- 企画・写真展の参加投票は、提出期限後も開催日前日まで回答できます。開催日の日本時間0時に会員の投票を停止し、期限超過の警告を消します。開催日未設定の旧写真展は日付を推測しません。
- 出展フォーム・展示シフト・投票・日程調整などは、提出期限後も警告を表示して受付します。運営が出展フォーム・シフトの受付状態やツールの受付を明示的に終了した場合は保存・提出できません。
- 期限後の参加投票はやることリストから除外します。出展者のシフトは、参加投票→作品提出→シフト提出の順序を保ちます。
- 作品数・長辺短辺・規格枠の超過は警告です。ブックは従来どおりこれらの上限の対象外です。必須項目、文字量、画像形式、アカウント・作品の所有権などの検証は維持します。
- 提出状況の詳細ボタンに警告アイコンを表示し、詳細の該当タブ・展示・作品から入力箇所へ移動できます。期限後提出は履歴に表示します。運営の後日の修正だけで、元の提出を期限後提出に変更しません。
- 「終了後」に結果を公開する投票・日程調整は、設定した提出期限での公開を保ちます。

画面を開いたまま提出期限や開催日0時を迎えた場合も、警告と投票ボタンを更新します。休止したタブに戻った場合も現在時刻で再確認します。サーバー側でも毎回受付・権限を検証します。

組写真の図では0.0mmになる間隔を非表示にします。数値欄で0を指定することはできます。寸法数字のクリック余白は拡大率に応じて狭くなり、400%以上では文字の範囲だけが反応します。寸法線はクリック対象にせず、数字を選択したキーボード操作は維持します。
