# 展示ボード群の面名

同じ展示室内で、展示ボード群の両面を A・B、C・D、E・F…と通しで表示します。接続済みのボードや旧形式で隣接するボード群は、一対の面名にまとめます。Z の次は AA、AB…へ続きます。

面名は展示室のボード群の順序から算出し、レイヤーの重ね順や非表示の切り替えでは番号を変えません。非表示にした群の文字は予約したままにします。ボード群を追加・削除・接続・分割した場合は現在の構成に従って再計算します。

平面図の面マーク、中央プレビュー、壁面選択、PNGプレビューおよびPDF・PNG・SVG出力の見出しに共通の表示規則を使います。保存済みの面IDは従来の A/B のまま保ち、作品・タイトルボード・図形・寸法の配置参照や裏面の左右方向は変更しません。既存データの移行は行いません。
