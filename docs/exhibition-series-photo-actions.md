# 組写真の写真追加・削除

出展フォームの写真枚数入力欄を廃止し、各組写真の「＋ 写真を追加」で1枚ずつ増やします。新しい組写真は1枚の入力欄から始まり、写真行の「この写真を削除」で対象だけを取り除きます。残った写真の添付・撮影情報・寸法・座標・回転は変更しません。写真枚数は実際の写真配列から自動集計します。

1作品につき最大100枚。すべて削除した状態は下書きとして保持でき、再読み込みでも写真を自動補充しません。提出には従来通り1枚以上の画像添付が必要です。運営の提出修正でも個別の追加・削除を使い、写真インデックスの変更時は配置ツールの選択・間隔編集中の状態をリセットします。保存済みの提出履歴や画像ファイル自体を削除する移行は行いません。
