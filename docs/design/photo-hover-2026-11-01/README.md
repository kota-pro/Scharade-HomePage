# ホバー表示と一括既読アイコンの更新

公開候補から出力した確認画像です。トップページのActivityカードと同じ半透明のグレーを写真に重ね、写真上の撮影情報を白文字にしています。ホバーとキーボードフォーカスで表示し、写真やハートのクリックは引き続き利用できます。

一括既読ボタンは指定のSVGを32pxで表示し、閉じるボタンの左に配置しています。操作名と44px以上のクリック範囲を維持しています。

- [PCのホバー表示](01-desktop-hover.png)
- [PCの通知ポップアップ](02-desktop-notifications.png)
- [スマホの通知ポップアップ](03-mobile-notifications.png)

名前・作品名・撮影情報と通知件数は隔離環境のサンプルです。本番データには保存していません。実フォントを使用し、確認画像を会話内へ出力してから本番へ反映しています。Chromium・Firefox・WebKitで既存の匿名いいね、写真別通知と個別・一括既読のシナリオを確認しました。
