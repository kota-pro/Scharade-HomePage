# トップページの共通写真ポップアップ

メイン写真とフィルム写真を共通のビューアーで開きます。Portfolioの保存済み情報・匿名いいね・作者リンク・28〜64ptのタイトル・12ptのキャプションを使い、最大表示から写真をクリックして情報欄を開閉できます。

メインとフィルムはそれぞれ別の写真送りです。フィルムの複製をクリックしても元の写真を開き、複製を枚数やいいねへ重複して数えません。選択中やポップアップ表示中はフィルムを停止します。

すべて最終Linux成果物と実フォントで出力しています。写真は既存のローカル素材、会員名・作品情報は隔離した合成データを使い、本番の会員情報・写真情報・いいねは書き換えていません。
