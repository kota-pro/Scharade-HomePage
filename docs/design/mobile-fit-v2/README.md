## iOSの幅計算について

WebKitには、余白を指定した日時入力がiOSで通常の入力欄と異なる幅になる不具合が報告されている。macOSでは再現しないとの記載があり、デスクトップWebKitの画面幅を狭める検証だけでは検出できない可能性がある。[WebKitの不具合報告301648](https://bugs.webkit.org/show_bug.cgi?id=301648)

今回の入力の外観・幅指定と1列化は、この種類の違いを避けるための対応を含む。ユーザーの端末で発生した問題と同一かどうかは実機で断定していない。
