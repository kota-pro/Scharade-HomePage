# 写真情報欄の文字サイズと作者位置

タイトルは情報欄の幅に合わせて28〜64ptで縮小し、キャプションは12ptで表示します。作者のアイコン・Portfolio名は情報欄を開く前と同じ右上の位置に置きます。低く狭い横画面では情報欄を少し広げ、28ptのタイトルと機材・設定が重ならないようにしています。

すべて最終Linux成果物と実フォントで出力した確認画像です。写真は既存のローカル素材を使い、作品名・作者・説明文は隔離した確認用データです。本番の写真情報やいいねを書き換えていません。
