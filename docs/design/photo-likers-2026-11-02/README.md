# いいねした会員の表示確認

ランキング・個人通知・写真の件数に、ログイン中に押した会員の名前を表示します。確認用の写真には会員2名と匿名3件、合計5件のいいねがあります。

最終Linux成果物と実フォントで出力しています。写真は既存の配信用素材、会員名・写真情報・いいねは隔離した合成データです。合成会員の表示名だけを確認用に変更し、権限・認証・公開設定は実装どおり検証します。本番の会員情報やいいねは書き換えていません。
