# Memberトップのベル配置

PCでは「〇〇さんのメンバーページです。」と同じ行の右端にベルを置き、body-contentsの内側右端へ揃えます。スマホではMember見出しと同じ行の右端に表示します。画面幅ごとにMember用ベルを1つだけ表示し、枠なしのアイコン・未読の印・通知ポップアップの操作を保持します。

最終Linux成果物と実フォントを使った確認画像です。ログイン・表示名・通知は隔離した合成会員のもので、本番の会員ページにはログインしていません。
