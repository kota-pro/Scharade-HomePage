# Lightroomの写真除外


通知・参加者・受付設定の「Lightroomアルバムを作成」（作成済みの場合は「設定を反映」）から、写真の除外設定を開きます。トップページの写真選択と同じように、サムネイル・検索・表示候補／除外中の絞り込み・ページ送りで写真を選び、最後のボタンで反映します。キャンセルやEscapeでは保存しません。

提出済みの写真を過去の版も含めて表示し、下書きだけの写真は含めません。除外はサイトの展示アルバムと、未送信のLightroom追加対象に反映します。提出内容、Drive原本、Lightroomに保存済みの写真は保持します。除外を解除するとサイトで再表示し、未送信分は通常の同期で追加します。既存アルバムは同じIDを更新します。

除外設定は写真展の変更番号を確認して保存します。同時更新は上書きせず、一覧の再読み込みを案内します。接続に失敗した場合も保存済みの除外設定を保持し、外部連携を再試行します。Adobeの公開API仕様ではアルバムへの追加を利用し、保存済みアセットの削除操作は行いません（https://github.com/AdobeDocs/lightroom-public-apis/blob/main/static/swagger.json）。
