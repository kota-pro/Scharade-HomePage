# 展示レイアウトの配置・検索

「余白を含めて均等配置」は、扉・窓・壁面の図形や設備を避けた使用可能な範囲ごとに、両端の余白と作品間隔を揃えます。壁に接する、名前に「柱」「pillar」「column」を含む平面図の図形も避けます。作品の順序と高さ、グループ化したタイトルボードの相対位置を保ちます。作品とタイトルボードが収まらない場合やロック中の場合は、元の配置を変更せず理由を表示します。

壁面の自動寸法は、段違いの作品配置でも各列の左右端から壁終端までを「左端まで」「右端まで」と表示します。寸法の数値編集は引き続き定規ツールだけで行います。

作品のホバーには、タイトルと寸法に加えて作者名・提出者名を表示します。作者名と提出者名が同じ場合は重複表示しません。図面の書き出しにはホバー表示を含めません。

作品タブの検索対象は配置済みの作品も含みます。「すべての作品／未配置／配置済み」で絞り込めます。配置済みの作品には展示室と壁面・ボード面・展示台を表示し、クリックするとその位置を表示します。配置や共有データを変更する操作ではありません。色タグや名前検索は従来どおり使用できます。

提出状況は氏名・作者名・LINE名に加え、提出済みおよび保存済み下書きの作品名でも検索できます。提出状況のフィルターと組み合わせて利用できます。
