# いいねした会員の表示

ログイン中に新しく押された写真のいいねは、会員単位で記録します。会員名とPortfolioへのリンクを、写真のいいね件数を閲覧できる本人・幹部・管理者に表示します。

- Adminの写真ランキングでは、各写真の概要に会員名を表示します。
- Memberの通知では、その通知の未読いいねを押した会員を表示します。通知の受信者だけが取得でき、写真を表示できない通知でも会員名を確認できます。
- Portfolio・Blog・Gallery・トップの写真では、ハート右側の件数を押すと一覧が開きます。ハートと件数は独立したボタンです。

写真とランキングは現在有効ないいね、通知は未読分を表示します。同じ会員が複数端末で押しても重複しません。取り消した会員の名前は一覧から消えます。会員名は現在のアカウント表示名を使い、Portfolioがあればそのページへのリンクを付けます。名前一覧とAPIにはメールアドレス・匿名識別子・内部の会員識別フィールドを返しません。

## 過去の記録と匿名のいいね

匿名でも従来どおりいいねできます。会員情報がない過去の記録は、件数と押した状態を維持して会員名を推測しません。会員名が分からない分は「その他のいいね」に含めます。既存のブラウザーのいいねはログイン後も取り消せ、ログイン中に新しく押し直すと会員として記録します。

## 保存と削除

`DATA_DIR/photo-interactions.json`のバージョン1を維持し、会員の記録には任意の`likerId`を追加します。会員名やメールアドレスの複製は保存しません。会員の有効ないいねは会員単位のキーで管理し、同じブラウザーで別のアカウントへ切り替えても相手の会員のいいねを取り消しません。

退会処理では会員との紐付けを除去し、名前を表示しなくなります。写真への合計件数は保持します。ランキングは名前一覧を現在の会員データから作るため、集計のキャッシュがあっても古い会員名を再表示しません。

## 確認

会員・匿名の混在、複数端末、同じブラウザーでのアカウント切り替え、取り消し、過去の記録、未読範囲、権限、送信者の偽装、退会・名前変更を単体検証します。PC・スマホ幅でランキング・通知・写真の件数を操作し、名前一覧の開閉、フォーカス復帰、いいねとの分離、各掲載先と公開範囲をブラウザー検証します。
