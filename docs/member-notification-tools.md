# 投票・日程調整・目安箱

「管理・運営 → 企画・通知 → 投票・日程調整・目安箱」から作成します。運営以上が質問と通知先を保存すると確認画面が開き、「公開する」で通知と回答受付を開始します。公開後も質問・選択肢・設定を編集できます。編集だけでは通知を再送しません。

## 画面の使い方

一覧では質問の検索と種類の絞り込みができます。管理画面は「質問・通知先」「受付・公開設定」「回答・結果」に分かれ、上部の目次から移動できます。回答の追加設定、結果公開、運営の権限は見出しを押して展開します。公開先や開始条件に必要な項目だけを表示します。

投票は画像付きの選択肢と集計バー、日程調整は横にスクロールできる結果表、目安箱は長文を展開できる投稿一覧で確認します。画像のプレビューはContactと共通の画面で、コピーとPNG保存を選べます。

## 削除

一覧と各ツールの管理画面にある「投票を削除」「日程調整を削除」「目安箱を削除」から削除できます。運営以上が、対象の質問と削除内容を確認してから確定します。下書き・受付中・受付終了のいずれも削除でき、質問・回答・添付・関連するサイト内通知が削除され、共有リンクも無効になります。画面からの復元はできません。

通常のお知らせの送信画面では「送信済みのお知らせ」の各通知を削除できます。通知だけを削除する場合、元の企画・投票・日程調整・目安箱と回答は残ります。配信済みの端末通知は取り消せません。古い通知はページを切り替えて確認できます。削除した通知は配信の再試行でも復活しません。

削除途中に障害が起きた場合、ツールは直ちに閲覧不可となり、通知ワーカーが添付・関連通知・一覧の整理を再試行します。削除記録に質問や回答本文は保持しません。

## 回答

- 投票：文章と画像の選択肢。複数選択・匿名・回答者による選択肢追加・終了日時は任意です。
- 日程調整：月間カレンダーで候補日を選択。同じ日を複数回選ぶと時間帯を分けられます。候補ごとに○・△・×で回答し、未回答は×とは区別します。時刻は日本時間です。
- 目安箱：20,000文字までの文章、URL、画像、PDF、Word、Excel、PowerPoint、UTF-8テキストを投稿できます。添付は1件20 MB、1投稿5件までです。複数投稿・匿名・終了日時は任意です。

受付中は自分の回答を変更・取り消しできます。選択肢の名前や画像を変更しても投票は保持します。削除した選択肢の票は現在の集計から外し、回答者には選び直しを案内します。複数選択・複数投稿を後から無効にしても過去の回答を消しません。質問・受付設定が回答中に変更された場合は、入力内容を控えて再読み込みし、変更内容を確認します。他の会員の回答や結果の公開設定の変更は、入力中の回答の保存を妨げません。

## 質問と結果の公開

質問のログインなし公開、回答受付、結果公開は別々に設定します。質問を公開しても回答は承認済みの通知先メンバーだけが行えます。ログインなしで回答内容や結果は閲覧できません。

投票・日程調整の結果は初期状態で通知先に公開します。公開先は通知先または運営・幹部・管理者以上、開始条件は常時・本人の回答後・受付終了後・日時指定から選択できます。公開終了日時や一時停止も設定できます。

目安箱の結果は初期状態で管理担当者のみが閲覧でき、投稿者は自分の投稿を確認できます。結果を公開するときは、公開先と投稿を選択します。「すべての投稿」は今後の投稿も自動公開します。「選択した投稿のみ」は本人による編集後に再公開が必要です。投稿画面にも公開範囲を案内します。

管理権限がある担当者は、会員向けの結果公開前や公開停止中も結果を確認できます。運営が作成したツールは運営以上、幹部・管理者が作成したツールは初期状態で幹部以上が結果を管理します。幹部以上は運営にも結果管理を許可できます。作成者の現在の役職ではなく、作成時の役職が基準です。

## 匿名

匿名回答の名前は通常の結果に含まれません。幹部以上は個別の名前確認ボタンで確認できます。幹部以上が許可した場合、結果管理権限のある運営も確認できます。確認操作は監査記録に残ります。匿名設定を後から解除しても、匿名で送信された既存の回答は通常の結果では匿名のままです。

## 画像コピー

結果の「結果を画像でコピー」でプレビューを作成します。目安箱は投稿を選択できます。長文や多数の候補は読みやすいサイズのままページ分割します。各画像をコピー、またはPNGで保存できます。匿名回答の名前を一時的に確認していても画像には含めません。目安箱の画像には本文・URL・画像・添付名を載せ、OfficeやPDFの内部ページは展開しません。

## 運用と復旧

保存先は既存の DATA_DIR です。`member-tools-index.json`、`member-tool-<UUID>.json`、`member-tool-asset-<UUID>.bin` を同じバックアップ世代で扱います。質問・回答・添付は公開メディアサービスへ送信しません。配信時にも閲覧権限を確認します。未使用の添付は24時間後に削除対象となり、通知ワーカーが定期整理します。会員削除処理では回答、添付、宛先、作成者参照も整理します。

公開の通知はツールに永続的に記録してから既存の通知へ反映します。通知IDで重複を防止し、障害後は `scharade-push-worker` が再試行します。Push配信の有効・無効にかかわらずサイト内通知の処理を行います。

更新時はWeb、`scharade-push-worker`、`scharade-exhibition-worker` を再起動します。戻す場合はリリース記録にあるソースとdistを復元して同じ3プロセスを再起動します。ツールの保存データを消す必要はありません。旧バージョンの退会処理はこの保存形式を認識しないため、切り戻し中の会員削除は新バージョンの処理で完了させてから行います。復旧で過去の本人情報を戻さないよう、既存の退会データ運用に従います。
