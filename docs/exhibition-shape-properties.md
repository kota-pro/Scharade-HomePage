# 図形の名前・注記とプロパティ

図形の名前は内部に表示し、白い余白でハッチングから分離します。名前が未設定なら図形の種類を表示します。注記は外側の下部へ折り返して表示します。注記は寸法・選択枠・整列・スナップに含めません。書き出しでは注記も収まる表示範囲を取り、SVGは文字をアウトライン化します。

輪郭線の標準は図面上の8mmです。既に指定された線幅は保持し、線幅欄を空にすると8mmへ戻ります。

プロパティは「名前、図形の寸法、塗りつぶし、輪郭線、反転、位置・向き、外観・注記、作者名の表示、壁の名前」の順で、初期状態では折りたたみます。クリック・キーボード操作で展開でき、同じ対象の編集中は開閉状態を保ちます。展示室の初期作成と図形追加の操作欄はすぐに使用できます。

図形追加は、クリック配置とドラッグの始点・終点で壁や図形の輪郭にスナップします。スマートガイドで切替、Altで一時解除できます。楕円・回転・反転・ペンの曲線は実際の輪郭を使い、非表示の図形と注記を対象にしません。グリッドより輪郭へのスナップを優先します。

名前の文字サイズは「名前」、注記の文字サイズは「外観・注記」で別々に指定します（0.1〜3000mm）。未設定の既存データは、それまでの共通文字サイズをそれぞれ引き継ぎます。コピー・再利用・パスの続きを描く操作でも個別設定を保持します。名前は図形内に収まるよう必要に応じて縮小し、注記のサイズとは連動しません。
