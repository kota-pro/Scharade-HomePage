# 図形の名前の表示切り替え

選択ツールで図形を選択し、プロパティの「名前」を開くと「図形の名前を表示」を切り替えられます。平面図・壁面図の図形、画像、電源記号、パス等に対応します。名前を非表示にしても登録名とレイヤー内の名前は保持し、注記・ハッチング・寸法は維持します。

設定は図形ごとの `showName?: boolean` で保存します。未設定の既存図形は従来どおり表示します。表示の変更は既存の保存履歴・元に戻す／やり直す・コピー・展示室再利用に従います。編集画面、中央プレビューおよびPDF・PNG・SVGの共有描画処理に反映されます。

保存時には真偽値だけを許可し、既存データの移行は行いません。図形の名前を隠したときは名前用の白い背景も描画しません。文字ツールの文字内容および作品名・作者名の表示設定は別の設定です。
