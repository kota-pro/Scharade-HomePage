# 連続する壁面の編集

同じ展示室内で、端点が接続し、同じ方向の直線上にある隣り合う壁を、一つの壁面図として表示します。展示室の始点を跨ぐ区切り、回転した直線、直線状のベジェ線にも対応します。曲線・折れ曲がり・離れた壁・逆方向の壁はまとめません。

壁面の選択肢は各連続壁につき一つです。全区間の作品・タイトルボード・開口部・図形・文字・壁に連動する設備を表示し、移動・追加・整列・間隔変更・定規・コピー/ペーストに同じ座標系を使います。高さが異なる場合は床を揃え、壁ごとの高さを表示して、低い区間からのはみ出しを検査します。

表示と操作に座標変換を使い、元の頂点・壁ID・区切り・壁名・高さを保持します。画面を開くだけでは壁を結合する保存やデータ移行は行いません。作品や図形の座標は元の壁を基準に保存します。開口部と設備は、継ぎ目を越えて移動したときに新しい壁を基準とする座標へ換算します。履歴・取り消し・共同編集は従来の対象IDをそのまま使います。

「壁の名前」では連続壁内の対象を選択して、区間ごとの名前を変更できます。寸法の表示・出力にも同じ壁面図を使います。保存形式やGoogle連携の設定変更はありません。

検証:
- `tests/exhibition-connected-walls.test.ts`: 連結判定、座標変換、元データの保持、異なる高さ、作品とタイトルボード、整列/間隔、寸法、コピー、設備、出力。
- `tests/browser/exhibition-connected-walls.spec.ts`: 実際の編集画面での移動・追加・整列・文字編集・保存/再表示・取り消し/やり直し、PCとスマホ。

## 180度付近の接続と角度入力

180°と−180°の向きは、周期を考慮した角度差で判定します。数値入力は表示用に丸めた角度を使わず、元の実角度から補正するため、微小なずれが残りません。接続時は端点の接触と、画面の方向入力と同じ0.1°精度での向きの一致を確認します。全区間を一つの基準方向と比較するため、差を区間ごとに累積させず、明確な折れ曲がり・曲線・逆向きの壁はまとめません。表示のために保存中の頂点を平坦化することはありません。
