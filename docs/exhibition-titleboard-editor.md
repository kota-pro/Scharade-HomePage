# タイトルボードの配置・印刷

提出結果の概要の備考ボタンと同じ行から「タイトルボードの配置を調整」「タイトルボードPDFを生成」を開きます。どちらも最初に印刷対象の一覧を表示します。「印刷しない」を付けた作品はPDFに含めません。同じタイトルでも作品IDで区別します。

標準配置に収まらない文章は警告を表示したまま提出できます。改行・タブの禁止、ふりがなの形式、入力上限、必要な写真・作品数・展示サイズなどの検証は維持します。配置の問題は提出状況・提出作品・QRとタイトルボード欄に赤い通知で示します。提出詳細の「QR・タイトルボード」の作品ごとの「配置を調整」からも開けます。

運営以上がタイトル・ふりがな、作者名、学年、キャプション、撮影場所、使用機材、撮影設定、QRコードの位置と枠を調整できます。ドラッグで移動、四隅で枠を変更、右側でmm・pt・行送りを指定します。1mmスナップ、倍率変更、画面移動、元に戻す・やり直すを使えます。Option/Altでドラッグのスナップを一時解除できます。文章そのものは既存の提出内容修正から編集します。

配置だけを `Exhibition.boardDesigns[workId]` に保存し、元の提出内容と提出版には書き込みません。保存には写真展と回答の変更番号が必要です。古い画面からの保存は409で拒否します。プレビューは変更番号を進めません。

編集画面のSVG、確認用PNG、展示室に配置したタイトルボード、PDFは共通の物理配置を使います。枠外・文字あふれ・項目の重なり・未確認のQRが残る作品は赤い通知を表示します。PDFに含める前に調整するか印刷から除外してください。PDFはA4に105×74.25mmを8枚配置し、Zen Old Minchoを埋め込みます。

新規作成する作品の「タイトルを「」で囲む」はオフから開始します。会員のフォームと運営の追加操作に共通です。既存の選択や、設定項目のない過去の作品の従来表示は維持します。

提出作品一覧と提出詳細の写真は既存の軽量WebPプレビューを維持し、クリック先の原画像・保存原本・GoogleやLightroomの連携内容は変更しません。
