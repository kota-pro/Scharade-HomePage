# 壁長の基準点とShift作図

プロパティの「壁の長さ」を入力すると、始点・終点の選択マーカーを表示します。この時点では保存データを変更しません。固定する端点をクリックするか、キーボードで選択してEnter/Spaceを押すと、反対側を動かして壁長を変更します。Escで取り消します。確定前の保存・画面切替では基準点の選択を案内します。同時編集で壁が変わった場合は上書きを拒否し、形状や開口寸法が成立しない変更も取り消します。定規による距離変更と同じ基準点方式です。

ペン、直接選択での頂点移動、頂点編集での接線操作はShiftで水平・垂直・45度刻みに制限します。スマートガイドが有効なら、既存の頂点や物体の角・中心を通る水平・垂直・斜めの線にも整合する位置へスナップし、ガイドを表示します。グリッドを併用しても45度の方向を維持します。Altで一時解除できます。選択済み頂点のShiftドラッグと、Shiftクリックによる選択解除を区別します。

空の展示室を描くペンにも同じ方向制限を適用します。補助線と未確定の基準点は図面データ・書き出しには含みません。
