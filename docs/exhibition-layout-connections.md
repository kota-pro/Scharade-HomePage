# 展示室の壁接続・名称・複製

ペンで壁の頂点から描き、別の壁の頂点を選ぶと、その間の外周を置き換えます。ペンで作った開いた線の端点も接続できます。片側を壁につないだ場合は反対側から描画を続け、もう一つの壁の頂点まで接続します。隣接していない壁の頂点同士では、置き換える壁の側を選んで確定します。未接続のままEnter・保存・ツール変更では確定できません。Escで元の図面を保持して取り消します。自己交差、分岐、32頂点超過、置換対象の壁にある作品・開口・設備は検証して拒否します。

壁の名前はプロパティの「展示室・壁の情報」から、図形・扉・窓の名前は選択後の「名前」から変更します。壁名は壁の固定IDに対応し、頂点の追加や外周編集で別の壁に移りません。名前を空欄に戻すと標準名になります。図形名はレイヤー等の識別名で、印刷する注記とは別です。共同編集・保存履歴・会場の再利用にも保存します。

Ctrl/Cmd+C、V、Dで、図形・文字・画像・自由線・扉・窓・展示台・展示ボード・寸法を複製できます。壁面・パネル面の図形にも対応し、グループと参照先を新しいIDへ移します。展示ボードの面上にある図形は同時に複製し、提出作品・ブック・作品のタイトルボードは複製しません。展示室そのものを選択した場合は、作品を除いた展示室を追加します。画像は同じ写真展内の元データを参照し、保存用会場テンプレートでは従来どおり画像を除外します。
