# 展示室エディター：スナップと文字の単位

- 図形・文字・窓・展示室の選択ツールによる拡大縮小は、グリッド／スマートガイドの設定に従って通常操作でスナップする。Shift は縦横比を維持し、Alt（Option）を押している間はスナップを解除する。操作中にキーを押す／離すだけでも表示を更新する。
- 文字の拡大縮小は縦横比を維持し、文字サイズに反映する。新しい文字に縦横の変形倍率を追加しない。既存の均一倍率は文字サイズへ取り込み、既存の縦横差は互換性のため維持する。
- Shift を押しながら移動すると、水平／垂直／45°ごとに方向が固定される。グリッド、スマートガイド、目線の高さへのスナップでその方向を崩さない。選択済みの物も Shift でドラッグでき、ドラッグを伴わない Shift クリックは従来どおり選択を切り替える。
- 文字サイズ（図形の名前・注記を含む）と輪郭線・自由描画の太さは pt で入力する。1 pt = 25.4/72 mm。データ保存形式・実寸・既存デフォルトは mm のまま維持する。従来の輪郭線標準 8 mm は画面上で 22.68 pt と表示される。表示のみで既存データを書き換えない。
- 文字編集ポップアップには色見本と編集可能なカラーコードを並べ、文字サイズ欄に pt を明示する。範囲選択した部分への色・太字・斜体・下線と、変更取消・保存・再読込・アウトライン書き出しを維持する。スマートフォンでは編集欄全体を画面内のポップアップに収める。不正な色／サイズは確定を止め、Escape で取消できる。

検証は合成データのみを使い、本番の図面を操作・移行しない。計算テストでは全4隅・回転・旧文字倍率・方向制約・壁面の窓を確認し、ブラウザでは標準スナップ、Option 切替、Shift 移動、文字のサイズ／色と保存・取消・再読込・書き出しを確認する。
