# 提出作品の表示用画像

提出作品一覧、提出詳細、組写真の配置図では `?preview=1&thumbnail=1` の表示用画像を使います。APIは長辺最大960px・WebP品質68で縮小・圧縮します。既存の1600px PNGプレビューがある場合はそれを使って変換し、ない場合は原本から生成します。小さい画像は拡大しません。

作品一覧のクリック先は `preview` を付けない元画像のURLです。元のJPEG／PNGを保存されたバイト列のまま返します。提出ファイル、Drive保存、印刷や書き出し用のPNGプレビューには変更を加えません。

表示用画像はアクセス権を確認してから返し、32MB・256枚を上限とするプロセス内キャッシュを使います。同じ画像の同時変換はまとめ、表示用変換の実行を2件に制限します。キャッシュを使用する場合もアクセス権を確認し、画像を取得する権限を広げません。追加の画像ファイルは保存しません。

通常のフォーム・展示レイアウト用の `?preview=1` は既存のPNGのままです。軽量化は提出作品一覧と提出詳細の画像に適用します。
