# 展示シフト

運営以上の「写真展管理」から、各写真展の「展示シフト」を開きます。開催期間・通常の展示時間と、必要に応じて初日・最終日の時間を設定します。時刻は日本時間です。開場から1時間ずつに分割し、最後の端数も1枠として扱います。

「集計・概要」の「シフト受付・自動割り当ての設定」で独立した受付期間を設定してください。写真展の参加通知の公開後、すべての承認済み会員のMemberページとカレンダーに表示します。出展者は参加投票・レイアウトフォーム提出を先に行います。出展しない会員は直接回答できます。「入れる時間はない」も提出として集計します。

設定した提出期限を過ぎても、受付状態が「受付中」であれば回答できます。期限超過を赤い警告で表示します。受付状態を「受付終了」にすると、下書き保存・提出を停止します。

「提出状況」は出展フォームと同じカード一覧で、名前・学年・提出状況・更新日時を表示します。氏名・LINE名で検索し、必須・任意や提出状況で絞り込み、詳細ボタンから回答を確認できます。「シフト表」は2名の枠で、不足している枠を赤で表示します。自動生成は空きを減らすことを優先し、禁止ペアと担当枠数の制限を守り、同枠希望・担当回数の均等化・同学年の組み合わせを順に考慮します。学年は登録情報を使い、未設定の人同士は同学年として優先しません。生成中も回答・画面の保存は可能です。入力や配置が変わった場合、古い生成結果は採用しません。

空き枠の「＋ 担当者を追加」から、未提出の会員も氏名・LINE名で検索できます。会員登録のない担当者は名前を直接入力して追加できます。手入力の担当者は同じ写真展内で再利用できます。手動追加しても回答が提出済みにはなりません。希望外や上限を超える配置には確認が表示されます。3名以上、同じ人の重複、禁止ペアの配置はできません。

担当者を2名順にクリックすると交換します。担当者を選んで空き枠を押すと移動します。手動配置は固定され、再生成しても残ります。「固定を解除」で自動生成の対象に戻せます。

編集した案は「確定シフトを公開」「更新版を公開」までは会員に公開されません。公開時だけ全会員へサイト通知と登録済みのプッシュ通知を送ります。回答変更後も公開版を維持し、運営に再確認を表示します。

再確認の表示は入力エラーではなく、案を作成・確認した時点と現在の回答や条件が異なるという案内です。保存済みの生成・公開情報から確認できる変更項目を表示し、公開前と公開済みを区別します。最新の希望から作り直す場合は「シフト案を自動生成」、配置を維持して確認する場合は「案を確認して保存」を使います。これらの操作だけで会員に公開・通知されることはありません。

Googleには既存の出展フォームと別の「（写真展名）（展示シフト）」スプレッドシートを作り、「希望回答」「確定シフト」を上書き更新します。保存先は写真展用アカウントの「保存年度年 / 公式サイト / 写真展名」です。通信に失敗してもサイトの保存は保持し、再試行します。写真展の削除時はシフトもバックアップ・削除の対象になります。

## 日付と時間の表・名前検索

シフト希望、希望人数の集計、編集用の案、公開結果は「列が日付・行が時間」の同じ表で表示します。初日・最終日の開場時刻が異なる場合は、時間の位置を保って枠を表示します。7日ごとに切り替えられ、横スクロールでも日付を確認できます。編集用・公開用の表は2人の名前を横に並べ、表内の縦スクロールを使わず全時間帯を表示します。長い名前は省略表示し、カーソルを合わせると全文を確認できます。自動配置した担当者には名前の右端に雷のアイコンを表示します。

希望入力には全選択・全解除・日別の選択を用意しています。会員用の画面は「シフト希望」「確定シフト」のタブで切り替えます。

運営の提出状況・担当者追加・シフト案の名前検索は、アカウント名とLINE名に加えて、紐付いた名簿の氏名・Portfolioの登録名、同じ写真展フォームの氏名・作者名でも検索できます。スペース、全角と半角、ひらがなとカタカナを区別しません。シフト表は一致する担当枠を強調し、「一致した枠へ移動」で該当の日付に移動します。確定シフトは表示されている担当者名で検索できます。

## やることリスト・初日と最終日の時間

シフト受付中、未提出または開催日時変更後の再提出が必要な会員には、ヘルプのやることリストにシフト希望を表示します。出展しない会員は任意の回答として表示し、出展者には作品提出後に入力する順序を案内します。下書きでは完了せず、正式提出（「入れる時間はない」を含む）で完了します。提出直後にリストを更新します。

写真展の新規作成と展示シフトの開催設定は、通常時間・初日・最終日を分けて表示します。「この日だけ時間を変更する」を選ぶと、その日の時刻入力が開きます。選ばない日は通常時間を使い、1日開催では最終日の別設定を使用しません。

## シフト表の担当者変更

運営以上は、シフト表の名前の横にあるチェンジアイコンから、その時間に希望を提出している別の会員へ変更できます。スマートフォンでは名前を約0.6秒長押ししても開けます。短いタップでの選択・移動と、表の横スクロールは従来どおりです。

候補は現在の開催日程に対する正式な希望回答を使い、同じ時間に配置済みの人を除外します。氏名・LINE名・登録名で検索でき、学年と現在の担当枠数を表示します。「同じ枠にしない人」の指定がある候補は選択できません。総担当枠数などの警告は従来の確認画面で確認します。

変更は手動の固定配置として案に保存し、希望回答自体や現在の公開版は変更しません。公開版に反映する場合は「更新版を公開」を押してください。他の操作でシフトが変更された場合は上書きせず、再確認を案内します。
